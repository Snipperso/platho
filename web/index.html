Open or install Platho

Use it as an app, outside stores and platform gates.

Platho is a static PWA. After installation, the app shell, docs, and bounded local encrypted history are cached on this device. The cache improves recovery, but it is not a universal backup. Network access is still required for contract reads, verified public feed updates, message-history retrieval, and sending transactions. Platho does not use a server account that can read your messages or hold your keys.

    If your browser does not show the install sheet, use the browser menu and choose Install app or Add to Home screen.

    Welcome to Platho

    A keyless, end-to-end encrypted messenger on TON.

    Your keys and messages live only on this device, encrypted — there is no server account that can read them or hold your keys. Private chats are end-to-end and post-quantum encrypted; everything is client-direct on TON, with no central gateway to block or censor.

    • End-to-end + post-quantum encrypted private chats
    • Your own keys — no server can read or hold them
    • Client-direct: no central point to block or censor

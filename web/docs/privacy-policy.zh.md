# 隐私政策

最后更新：2026年10月22日

Platho 是一款没有后端的即时通讯工具。本文档篇幅很短，因为可披露的内容极少；但凡有信息确实离开你的设备，本文档都会写得很具体。

## 我们收集什么

什么也不收集。

Platho 没有服务器。本应用是一个完全在你的浏览器中运行的静态页面。我们不运营任何账户系统、用户数据库、统计分析、崩溃报告或广告系统。我们看不到你的消息、联系人、余额或活动记录，因为这些内容根本不会发送给我们。

我们不索取电子邮件地址、电话号码或姓名。

## 什么留在你的设备上

- 你的 24 个单词的恢复短语，以及由它派生出的钱包密钥和消息密钥。
- 你的消息记录。（未发送的草稿只保存在内存中，页面关闭即消失。）
- 你给联系人起的名字，以及你对他们设置的“置顶”和“不标记为未读”。
- 你为钱包起的名称——以普通文本保存，以便锁屏界面在输入任何密码之前显示它们。
- 你的设置，其中包括可选填的公共 TON 节点服务商 API 密钥。

这些数据都不会到达我们这里，但保护方式并不相同——因此下面逐项说明，而不是用一句话
概括全部：

- **助记词及由其派生的密钥**用你自己选择的密码加密（AES-GCM-256，密钥派生使用
  PBKDF2-SHA-256）。没有这个密码，无论是我们还是拿到设备的人都无法读取。
  如果由密码管理器替你保存这个密码，那么本设备上钱包的安全程度就取决于这个管理器——通常是
  你在设备上的账户，如果它会同步，还包括它的云端。
- **消息历史、你的对话和群组的密钥、你给联系人起的名字，以及谁最先给你写信的记录**，都用由你的恢复短语派生出的密钥加密。这些密钥只在钱包解锁期间存在，从不写入设备；因此，没有你的密码，浏览器文件的副本——备份、磁盘镜像、同一台电脑上的另一个账户——读不出其中任何内容：读不出消息，也读不出密钥和名字。在保存着你钱包的设备上，应用为快速显示图片、资料和帖子而保留的内容，以及你关注的公开频道和读到了哪里，也同样如此。
- **设置**——主题、语言——以普通文本保存，任何内容都不会发给我们。在没有钱包的设备上，你关注的公开频道以及读到了
  哪里也以同样方式保存，直到在该设备上创建或恢复钱包。其中唯一的秘密，即节点服务商的可选 API 密钥，不以明文存放，
  而是用浏览器保存在本设备上的密钥封存。

清除浏览器数据会从设备上删除以上全部内容。能用你的助记词找回的内容来自区块链：你的消息
发布在链上，打开你的会话和群组所需的密钥、你的笔记和订阅也保存在链上，并用由助记词派生
的密钥加密——没有助记词，包括我们在内的任何人都无法读取或恢复它们。在 Telegram 内你还可以
再保存一份副本，见下文 Telegram Mini App 一节：一份加密的钱包副本，清除浏览器数据不会触及它。

## 什么在设计上就是公开的

**私人消息在发布前已在你的设备上完成加密**，只有指定的接收者才能读取其内容。

**公开帖子不加密。** 它们以明文形式写入 TON 区块链，并且是永久性的：我们、管理员、政府，以及作为作者的你本人，都无法将其删除。凡是日后可能需要撤回的内容，都不要公开发布。

区块链是一个公开账本。即使是加密消息，某笔交易是否发生、发生的时间及其花费，任何人都能看到。钱包地址是公开的。如果你在其他地方把某个地址与自己的身份关联起来，该地址的活动就可能被关联到你本人。

**举报和表态是从您钱包发出的公开交易。**当您举报或对某条帖子表态时，交易由您的钱包发往一个任何人都能根据该帖子算出的地址，因此任何人——包括这条帖子的作者——都能看到是哪个钱包举报或表态了。被驳回的举报和被解除的处罚只撤销其效果，不撤销记录：交易将永久留在链上。

## 你的设备会联系的第三方

本应用没有属于我们的服务器可供通信，因此它直接与公共 TON 基础设施通信。当你使用Platho 时，你的浏览器会向以下地址发送请求：

- `toncenter.com`
- `tonapi.io`
- `nft.fragment.com`

这些服务商必然会看到你的 IP 地址以及你的设备发出的请求，它们各自遵循自己的隐私政策，而我们无法控制这些政策。除你选择保存在 Telegram 中的内容（见下文 Telegram Mini App 一节）外，这是关于你的信息离开你的设备、抵达区块链本身以外第三方的唯一环节。如果你使用 VPN 或 Tor 网络，这些服务商看到的将是它们的信息。

如果你自行提供了其中某家服务商的 API 密钥，该密钥会保存在你的设备上，并且只会发送给该服务商；如果你把钱包保存在 Telegram 中，它还会以加密形式保存在那里的钱包副本旁边（见下文）。

## Telegram Mini App

Platho 也可以作为 Mini App 在 Telegram 内运行。在该模式下，Telegram 自行决定向本应用提供什么内容，以及记录你使用 Telegram 的哪些信息；这部分适用 Telegram 自己的隐私政策，而非本政策。

在该模式下，你的钱包存放在两个位置之一，存放在哪里由你在“设置”→“钱包保存位置”中选择。**默认情况下，它只存放在本设备上**：它的副本不会发送给 Telegram（只有下文所述的几个小标记会发送）；如果设备上的数据丢失（Telegram 可能会清除应用的存储，在 iPhone 上尤其如此），只有它的 24 个单词或它的密钥文件才能将它找回。

**如果你选择将它保存在 Telegram 中，你的钱包的一份加密副本会保存在 Telegram 的云存储（CloudStorage）中**，这样任何登录了你的 Telegram 账户的设备都可以用你的密码打开它。这份副本与你设备上保存的、用你的密码加密的记录完全相同：恢复短语和钱包地址都在加密内容之中。旁边保存的是解密所需的参数，以及一个由恢复短语派生出的标识符，应用凭它识别自己的副本；没有恢复短语，就无法把这个标识符与你的地址关联起来（你的密钥文件中，它与地址保存在一起）。Telegram 将这份副本保存在其服务器上，并将其与你的 Telegram 账户关联；没有你的密码就无法解密，因此请选择一个强密码，并且不要在其他地方使用。如果你为节点服务商提供了 API 密钥，它会保存在副本旁边，并用由你的恢复短语派生出的密钥加密。 每个副本还带有一个版本号，应用据此判断哪个副本更新；以及一个用由恢复短语派生的密钥生成的签名，应用据此核实副本及其版本来自你的钱包。

你在 Telegram 中保存的每个钱包在那里都有自己的副本，用该钱包的密码加密；在设备上创建或选择另一个钱包不会删除其中任何一个。登录你的 Telegram 账号的每台设备都会列出保存在那里的钱包——在锁屏界面和“设置”→“其他钱包”中——每个钱包都用自己的密码打开。钱包的密码更改后，它在 Telegram 中的副本也会换成新密码。以前在某台设备上使用过的钱包，也以同样的方式保存在该设备上。

Telegram 的云端还保存着几个小值：一条你已关闭快速开始的记录、一个你已确认某个钱包 24 个单词的标记，以及在钱包密钥文件尚未保存期间的一个标识；这个标记和这个标识只有该钱包自己才能识别。它们都不包含地址。只有在 Telegram 确认应用是从官方机器人 @PlathoBot 打开时，应用才会写入 Telegram 的云端。当 Telegram 保存某个钱包的副本时，你为该钱包起的名称会保存在副本旁边，并用由该钱包助记词派生的密钥加密——Telegram 无法读取——那里的最后一个副本删除时，名称也随之删除。

“删除 Telegram 中的副本”会删除你的钱包在那里的副本以及保存在其旁边的 API 密钥；“忘记此钱包”会从本设备删除“其他钱包”中的钱包，并删除它在 Telegram 中的副本。本应用自带的“清除本地数据”只清除本设备——它不会从 Telegram 删除任何内容——而清除 Telegram 缓存或浏览器数据后，Telegram 中的副本仍会保留。在 Telegram 之外，钱包不会被复制到任何地方。

## 儿童

Platho 不面向 13 岁以下的儿童。

## 变更

如果本政策发生变更，顶部的日期也会随之变更。当前有效的版本始终是应用内以及platho.app 上发布的版本。

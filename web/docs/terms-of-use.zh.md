# 使用条款

最后更新：2026年8月18日

Platho 是一个直接与 TON 区块链通信的静态应用。没有公司为你保管资金，没有服务器存储你的消息，也没有任何客服可以撤销一次失误。制定这些条款，主要是为了在你依赖本应用之前，把上述后果讲清楚。

使用 Platho 即表示你接受以下条款。

## 1. Platho 是什么

Platho 是一款自主保管（self-custodial）的即时通讯工具和 TON 钱包。它在你的浏览器中运行，或作为 Mini App 在 Telegram 内运行。它把消息和交易直接从你的设备发布到 TON区块链上。

我们不是银行、托管方、支付服务机构或经纪商。我们从不占有你的资金，也无法转移、冻结或退还这些资金。

## 2. 你的密钥与你的责任

对你的账户、消息和资金的访问权限，全部取决于一组 24 个单词的恢复短语。

**如果你丢失了该短语，它所保护的一切将永久丢失。** 没有重置，没有找回链接，也没有任何管理员可以提供帮助。包括我们在内，没有任何人能够将其恢复。

**如果他人取得了该短语，他们将获得与你相同的访问权限。** 切勿分享，切勿拍照，切勿在并非由你自己打开的网站上输入它。

妥善保存该短语的副本，完全是你自己的责任。

## 3. 操作不可逆

Platho 所做的一切都会记录在公开的区块链上。

- 已发布的帖子**无法被任何人删除或编辑**，包括其作者本人。发布前请三思。
- 已发送的交易无法撤回。地址输错就意味着资金被发给了陌生人，或者发到了不存在的
  地方。
- 网络手续费支付给区块链，而不是支付给我们，并且不可退还——包括手续费已经花掉之后
  操作却失败的情形。

## 4. 你不得发布的内容

你对自己所写和所发布的内容承担全部责任。你不得使用 Platho 发布在你所在地属于违法的内容、侵犯他人权利的内容、描绘虐待儿童的内容，或意在威胁、欺诈或骚扰的内容。

请理解这在实践中意味着什么：**该协议没有内容审核，也没有删除功能。** 我们无法删除帖子、封禁作者或关停频道，其他任何人同样做不到。这是系统本身的属性，而非政策上的选择，也正因如此，上述规则在这里比在其他地方更为重要。

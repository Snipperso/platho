# Platho について

Platho は、メッセージ、アイデンティティ、プロフィール、履歴、そして自分自身の資金へのアクセスといった基本的なデジタル生活を、他者のインフラに依存することにうんざりした人々のためのコミュニケーションアプリです。

通常のインターネットは、それを支配する人々にとってあまりにも都合よく作られています。アカウントは閉鎖されうる。アクセスは制限されうる。履歴は削除されうる。ユーザーが自分の生活の一部をすでにプラットフォームへ移してしまった後で、ルールは変更されうる。そこではユーザーは所有者ではありません。ユーザーは、プラットフォームが許す限りにおいてのみ存在する借り手です。

Platho はそのモデルに抗って作られています。

Platho における中核的な操作は、ユーザーのウォレットによって固定され、オープンなスマートコントラクトを通じて実行されます。ウォレットは制御の根源であり続けますが、日常的なアプリの活動は、毎回ウォレットを直接さらすのではなく、Vault と署名済みコマンドを通じて実行できます。これはシステムを完璧にするものではありません。それは通常のプラットフォームの中心的な欠陥を取り除きます。すなわち、ルールを書き換えたり、アクセスを遮断したり、本来ユーザーに属するべきものの制御を奪ったりする隠された能力です。

プライベートメッセージは、暗号化されたカプセルエントリとしてオンチェーンに固定されます。重い暗号化本体は、受理された TON トランザクション本体に載せられて運ばれ、受理された TON トランザクション履歴から復元され、CapsuleHub のハッシュと照合して検証されます。したがって可用性は、プロバイダーの履歴カバレッジとユーザーのローカル暗号化キャッシュに依存します。パブリックメッセージ、プロフィール、名前は、閉じたデータベースの代わりに検証可能なコントラクト状態を使用します。これにより、サーバー、オペレーター、そしてその週にたまたま都合のよいポリシーへの依存が軽減されます。

Platho はこのアーキテクチャのコストを隠しません。ブロックチェーンは公開されています。操作にはお金がかかります。ユーザーのミスは取り返しのつかないものになりうる。失われたシードフレーズはサポートを通じて復元できず、Platho は永続的なアーカイブではありません。コンパクトなカプセルエントリは保持期間の後に削除されうる一方、古い本体の取得はプロバイダーの履歴またはユーザーのローカルキャッシュに依存します。これは厳しいモデルです。

個人ウォレットと Vault は分離されています。ウォレットは制御の根源であり続けます。それは資金を入金・出金し、鍵を制御します。Vault は、ウォレットとパブリックネットワークの間にある保護的なコントラクト層です。ユーザーは限られた量の GRAM/ATH を Vault に移し、公開、プロトコル支払い、その他のアプリ操作は、内部残高と署名済みコマンドを通じて実行されます。これにより、オンチェーンでのウォレットの直接的な露出が減り、日常的なアプリの活動にさらされる価値の量が制限されます。

ATH はプロトコルのユーティリティトークンです。ユーザー名、アバターの更新、そしてエアドロップ後のプロトコル手数料の割引に使用されます。その役割は、アプリ内での実際の利用と結びついています。

ATH はシステム参加者のために設計されています。供給量の意味ある割合が、初期アドレスへの閉じた割り当てを通じてではなく、ユーザーの活動を通じて配布されます。これにより、経済は狭い保有者集合への依存が減り、実際のネットワーク利用とより結びつくものになります。

Platho には、ユーザーの残高に対する隠された管理的な制御はありません。コントラクトは、他人の資金を差し押さえたり、残高を書き換えたり、ユーザーの操作を一時停止したり、プロトコルルールをアップグレードしたりするための恣意的な管理者スイッチを誰にも与えません。V1 には、依然として限定的で文書化されたローンチ時の権限が存在します。ジェネシスのバインドとシール、プール後の BuybackBurn ルートの凍結、プール後の MarketStabilitySeller の価格設定の凍結、そしてプリフライト後の一方向 FeeAccumulator バイバック分配の有効化です。

要点はシンプルです。デジタル生活はプラットフォームの許可に依存すべきではありません。メッセージ、ユーザー名、プロフィール、そして資金は、現実のシステムがそれを可能にできる限りにおいて、ユーザーのものであるべきです。

Platho は快適な檻になろうとしているのではありません。基本的なデジタルなものごとに対する制御が、サーバー、データベース、あるいはアクセスルールを支配する者にではなく、それを使う人へと戻ってくる、そんなツールになろうとしているのです。

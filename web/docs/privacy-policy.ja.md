# プライバシーポリシー

最終更新: 2026年8月18日

Platho はバックエンドを持たないメッセンジャーです。開示すべきことがごくわずかしかないため、本書は短いものになっています。そのうえで、あなたの端末から実際に何かが外へ出る箇所については具体的に記します。

## 収集する情報

何も収集しません。

Platho のサーバーは存在しません。本アプリケーションは静的なページであり、すべてブラウザ内で動作します。当方はアカウントシステム、ユーザーデータベース、アナリティクス、クラッシュレポート、広告のいずれも運用していません。あなたのメッセージ、連絡先、残高、活動のいずれも当方には送信されないため、当方がそれらを見ることはできません。

メールアドレス、電話番号、氏名をお尋ねすることもありません。

## 端末内に留まる情報

- 24 語のリカバリーフレーズ、およびそこから導出されるウォレット鍵とメッセージング鍵。
- メッセージ履歴と下書き。
- 設定（公開 TON ノードプロバイダー向けの任意の API キーを含む）。

これらのデータはブラウザのローカルストレージに保存され、あなたが選んだパスワードで暗号化されます（AES-GCM-256、鍵導出は PBKDF2-SHA-256）。当方がこれを受け取ることは決してありません。ブラウザのデータを消去すればこれらは削除され、リカバリーフレーズがなければ、当方も他の誰も復元することはできません。

## 設計上公開される情報

**プライベートメッセージは公開される前にあなたの端末上で暗号化され**、その内容を読めるのは意図された受信者だけです。

**公開投稿は暗号化されません。** 公開投稿は平文で TON ブロックチェーンに書き込まれ、恒久的に残ります。当方も、管理者も、政府も、著者であるあなた自身も、それを削除することはできません。後から取り下げる必要が生じうるものを、公開の場に投稿しないでください。

ブロックチェーンは公開台帳です。暗号化されたメッセージであっても、取引が行われたという事実、その時刻、その費用は誰にでも見えます。ウォレットアドレスは公開情報です。他の場所でアドレスをあなたの身元と結び付けた場合、そのアドレスの活動はあなたと関連付けられうるものになります。

## あなたの端末が接続する第三者

本アプリケーションには通信すべき当方のサーバーが存在しないため、公開されている TON インフラストラクチャと直接通信します。Platho を利用すると、あなたのブラウザは次の宛先へリクエストを送信します。

- `toncenter.com`
- `tonapi.io`
- `mainnet-v4.tonhubapi.com`

これらのプロバイダーは、その仕組み上どうしても、あなたの IP アドレスと端末が行うリクエストを見ることになります。またこれらは、当方が管理していない各社独自のプライバシーポリシーの下で運営されています。ここが、ブロックチェーン自体以外の相手へ、あなたに関する情報が端末から出ていく唯一の箇所です。VPN や Tor ネットワークを利用している場合、これらのプロバイダーに見えるのは、その代わりに VPN や Tor 側の情報となります。

これらのプロバイダーのいずれかについて、あなた自身の API キーを設定した場合、そのキーは端末内にローカルに保存され、当該プロバイダーにのみ送信されます。

## Telegram Mini App

Platho は Telegram 内で Mini App として動作させることもできます。そのモードでは、アプリケーションに何を提供するか、また Telegram の利用について何を記録するかは、Telegram 自身が定めます。それは本ポリシーではなく、Telegram 自身のプライバシーポリシーの対象となります。

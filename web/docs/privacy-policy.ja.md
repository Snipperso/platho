# プライバシーポリシー

最終更新: 2026年10月22日

Platho はバックエンドを持たないメッセンジャーです。開示すべきことがごくわずかしかないため、本書は短いものになっています。そのうえで、あなたの端末から実際に何かが外へ出る箇所については具体的に記します。

## 収集する情報

何も収集しません。

Platho のサーバーは存在しません。本アプリケーションは静的なページであり、すべてブラウザ内で動作します。当方はアカウントシステム、ユーザーデータベース、アナリティクス、クラッシュレポート、広告のいずれも運用していません。あなたのメッセージ、連絡先、残高、活動のいずれも当方には送信されないため、当方がそれらを見ることはできません。

メールアドレス、電話番号、氏名をお尋ねすることもありません。

## 端末内に留まる情報

- 24 語のリカバリーフレーズ、およびそこから導出されるウォレット鍵とメッセージング鍵。
- メッセージ履歴。（送信していない下書きはメモリ上にだけ置かれ、ページを閉じると消えます。）
- 連絡先に付けた名前と、どの連絡先をピン留めしたか・未読として数えないようにしたか。
- ウォレットに付けた名前（ロック画面でパスワードより前に表示できるよう、通常のテキストとして保存されます）。
- 設定（公開 TON ノードプロバイダー向けの任意の API キーを含む）。

どれ一つとして当方には届きませんが、守られ方は同じではありません。すべてをまとめて
言い切るのではなく、一つずつ記します。

- **リカバリーフレーズとそこから導出される鍵**は、あなたが選んだパスワードで暗号化
  されています（AES-GCM-256、鍵導出は PBKDF2-SHA-256）。そのパスワードなしでは、
  当方にも端末を手にした誰にも読めません。
  パスワードマネージャーにこのパスワードを保存している場合、この端末のウォレットの安全性は
  そのマネージャー次第です。通常は端末のアカウント、同期している場合はそのクラウドです。
- **メッセージ履歴、会話とグループの鍵、連絡先に付けた名前、そして誰が最初にあなたに連絡してきたかの記録**は、リカバリーフレーズから導出した鍵で暗号化されています。これらの鍵はウォレットのロックが解除されている間だけ存在し、端末に書き込まれることはありません。そのため、ブラウザーのファイルのコピー（バックアップ、ディスクイメージ、同じコンピューターの別アカウント）は、パスワードなしではそのどれも読めません。メッセージも、鍵も、名前も読めません。ウォレットを保管している端末では、画像やプロフィール、投稿をすばやく表示するためにアプリが保持するデータ、そしてフォローしている公開チャンネルとどこまで読んだかも、同じように扱われます。
- **設定**（テーマ、言語）は通常のテキストとして保存され、私たちには一切届きません。ウォレットのない端末では、フォローして
  いる公開チャンネルとどこまで読んだかも同じように保存されます（その端末でウォレットを作成または復元するまで）。その中で
  唯一の秘密である、ノードプロバイダーの任意の API キーは、平文で保存せず、ブラウザーがこの端末に保管する鍵で
  封印されています。

ブラウザーのデータを消去すると、これらはすべて端末から削除されます。リカバリーフレーズで取り
戻せるものは、ブロックチェーンから戻ってきます。メッセージはそこに公開されており、会話や
グループを開くための鍵、メモ、購読もそこに保存されています。いずれもフレーズから導出した
鍵で暗号化されているため、フレーズがなければ、当方を含め誰も読むことも復元することもでき
ません。Telegram 内にもう一つコピーを保管することもできます（下の Telegram Mini App の項を参照）。
ブラウザーのデータを消去しても届かない、ウォレットの暗号化コピーです。

## 設計上公開される情報

**プライベートメッセージは公開される前にあなたの端末上で暗号化され**、その内容を読めるのは意図された受信者だけです。

**公開投稿は暗号化されません。** 公開投稿は平文で TON ブロックチェーンに書き込まれ、恒久的に残ります。当方も、管理者も、政府も、著者であるあなた自身も、それを削除することはできません。後から取り下げる必要が生じうるものを、公開の場に投稿しないでください。

ブロックチェーンは公開台帳です。暗号化されたメッセージであっても、取引が行われたという事実、その時刻、その費用は誰にでも見えます。ウォレットアドレスは公開情報です。他の場所でアドレスをあなたの身元と結び付けた場合、そのアドレスの活動はあなたと関連付けられうるものになります。

**報告とリアクションは、あなたのウォレットからの公開トランザクションです。** 投稿を報告したりリアクションしたりすると、そのトランザクションはあなたのウォレットから、誰でも投稿から計算できるアドレスへ送られます。そのため、その投稿の作者を含む誰でも、どのウォレットが報告やリアクションをしたかを見ることができます。却下された報告や解除された制裁は効果を取り消すだけで、記録は消えません。トランザクションはチェーンに永久に残ります。

## あなたの端末が接続する第三者

本アプリケーションには通信すべき当方のサーバーが存在しないため、公開されている TON インフラストラクチャと直接通信します。Platho を利用すると、あなたのブラウザは次の宛先へリクエストを送信します。

- `toncenter.com`
- `tonapi.io`
- `nft.fragment.com`

これらのプロバイダーは、その仕組み上どうしても、あなたの IP アドレスと端末が行うリクエストを見ることになります。またこれらは、当方が管理していない各社独自のプライバシーポリシーの下で運営されています。あなたが Telegram に保管することを選んだもの（下の Telegram Mini App の項を参照）を除けば、ここが、ブロックチェーン自体以外の相手へ、あなたに関する情報が端末から出ていく唯一の箇所です。VPN や Tor ネットワークを利用している場合、これらのプロバイダーに見えるのは、その代わりに VPN や Tor 側の情報となります。

これらのプロバイダーのいずれかについて、あなた自身の API キーを設定した場合、そのキーは端末内に保存され、当該プロバイダーにのみ送信されます。また、ウォレットを Telegram に保管している場合は、Telegram にあるウォレットのコピーの横にも暗号化して保管されます（下記参照）。

## Telegram Mini App

Platho は Telegram 内で Mini App として動作させることもできます。そのモードでは、アプリケーションに何を提供するか、また Telegram の利用について何を記録するかは、Telegram 自身が定めます。それは本ポリシーではなく、Telegram 自身のプライバシーポリシーの対象となります。

このモードでは、ウォレットは二つの場所のいずれかに置かれ、どちらにするかは「設定」→「ウォレットの保存場所」で選べます。**既定では、ウォレットはこの端末にのみ置かれます。** そのコピーが Telegram に送信されることはありません（送信されるのは後述の小さな印だけです）。端末のデータが失われた場合（Telegram はアプリケーションのストレージを消去することがあり、特に iPhone で起こります）、ウォレットを取り戻せるのはその 24 語か鍵ファイルだけです。

**Telegram に保管することを選んだ場合、ウォレットの暗号化コピーが Telegram のクラウドストレージ（CloudStorage）に保存されます。** これにより、あなたの Telegram アカウントにサインインしているどの端末からでも、パスワードでそれを開けます。このコピーは、端末に保存されているのと同じ、あなたのパスワードで暗号化された記録です。リカバリーフレーズとウォレットのアドレスは暗号の内側にあります。その横に置かれるのは、復号に必要なパラメーターと、リカバリーフレーズから導出された識別子で、アプリはこの識別子で自分のコピーを見分けます。フレーズがなければ、この識別子をあなたのアドレスと結び付けることはできません（鍵ファイルには、アドレスの横にこの識別子も記録されています）。Telegram はこのコピーを自社のサーバーに保存し、あなたの Telegram アカウントに関連付けます。パスワードがなければ復号できないため、他では使っていない強力なパスワードを選んでください。ノードプロバイダーの API キーを設定している場合、そのキーはコピーの横に、リカバリーフレーズから導出した鍵で暗号化して保管されます。 各コピーにはバージョン番号も付いており、アプリはそれでどのコピーが新しいかを判断します。また、リカバリーフレーズから導出した鍵による署名も付いており、アプリはそれでコピーとそのバージョンがあなたのウォレットのものであることを確かめます。

Telegram に保管するウォレットには、それぞれ Telegram 内に専用のコピーがあり、そのウォレットのパスワードで暗号化されています。端末で別のウォレットを作成したり選んだりしても、どのコピーも削除されません。あなたの Telegram アカウントでログインしているすべての端末に、そこに保管されているウォレットが表示され（ロック画面と「設定」→「その他のウォレット」）、それぞれ自身のパスワードで開きます。ウォレットのパスワードを変更すると、Telegram 内のそのコピーも新しいパスワードになります。以前に端末で使ったウォレットも、同じようにその端末上に保管されます。

Telegram のクラウドには、ほかにもいくつかの小さな値が保存されます。クイックスタートを閉じたという記録、ウォレットの 24 語を確認したという印、そしてウォレットの鍵ファイルがまだ保存されていない間だけ置かれる標識です。この印と標識は、そのウォレット自身にしか識別できません。どれにもアドレスは含まれません。アプリが Telegram のクラウドに書き込むのは、公式ボット @PlathoBot から開かれたことを Telegram が確認した場合だけです。Telegram がウォレットのコピーを保管している場合、そのウォレットに付けた名前もコピーの横に保管されます。そのウォレットのリカバリーフレーズから導いた鍵で暗号化されるため Telegram は読めず、そこにある最後のコピーが消えると一緒に消えます。

「Telegram のコピーを削除」は、Telegram にあるウォレットのコピーと、その横に保管された API キーを削除します。「このウォレットを忘れる」は、「その他のウォレット」のウォレットをこの端末から削除し、Telegram にあるそのコピーも削除します。アプリケーション自身の「ローカルデータを消去」はこの端末だけを消去し、Telegram からは何も削除しません。また、Telegram のキャッシュやブラウザーのデータを消去しても、Telegram 内のコピーは残ります。Telegram の外では、ウォレットはどこにもコピーされません。

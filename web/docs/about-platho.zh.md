# 关于 Platho

私密通信是一项权利，而非特权。自由表达同样如此。Platho 的构建，正是为了让二者成为现实——在一个无人能悄然将其夺走的地方。

一封封缄的信件，曾经只关乎书写它的两个人，而与旁人无涉。到了网络世界，这一点不再成立。对话被搬到了他人的服务器上，在那里，它们可以被阅读、被移交、被限速，或被抹去——而且规则可以在不征询您意见的情况下发生改变。Platho 的构建思路则恰恰相反。

**您的言辞归您所有。** 私密消息经过端到端与后量子加密——只有您和与您通信的人才能读到。没有任何服务器、任何运营者，也没有任何政府、法院或法律能够将其开启，因为不存在一个让您的对话公开摊放的中心场所，而且除您之外无人持有密钥。

**没有人能对您扳动开关。** 没有可供封锁的中心网关，没有可供传唤的公司收件箱，也没有其政策下周就会变更的服务器。Platho 直接从您的设备出发，运行在开放的公共网络之上，因此没有任何运营者横亘在您与您所交谈的人之间——也不存在任何单一节点，能让人在此强加审查。

**无法被悄然抹去的言论。** 您的公开帖子存续于开放、可验证的状态之上，而非存放在一个可以被改写或清除、以让某些内容凭空消失的私有数据库中。您在公开场合发布的任何内容都将保持公开——没有人，甚至包括您自己，能够在事后将其删除或更改。

**您是所有者，而非租客。** 您的身份、您的消息、您的名字以及您的资金，都锚定在您自己的钱包之上——而非锚定在一个他人可以关闭、暂停或清空的账户之上。Platho 背后的任何机制，都不会赋予任何人一个隐秘的开关来扣押您的余额、冻结您或让您噤声。

这份自由伴随着实实在在的责任。您掌管着自己的密钥：一旦恢复助记词遗失，客服无法为您找回，而在开放网络上的操作是永久性的，并且会耗费真金白银。Platho 是一件工具，它把对您的私人生活、您的言论以及您的金钱的掌控权，交还给它们本应归属的那个人。

私密通信是一项权利。言论自由是一项权利。Platho 之所以存在，就是为了让没有任何服务器、任何运营者、任何审查者，能够替您作出相反的裁断。

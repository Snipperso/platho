# ATH 白皮书

## Platho 协议代币

ATH 是 Platho 的实用型代币。它用于活跃度奖励、`.ath` 用户名、头像更新、市场稳定性售卖、回购与销毁。

ATH 不是治理型代币。它不赋予任何人改写余额、暂停操作、增发或变更用户所有权的权力。它的职责是驱动应用内经济，并把使用 Platho 这件事与链上记账绑在一起。

本文描述 Platho 中的 ATH 模型。

## 核心参数

ATH 的总量固定：

```text
100,000,000 ATH
```

上线参考价：

```text
1 ATH = 0.001 GRAM
```

上线时的完全稀释估值：

```text
100,000,000 ATH * 0.001 GRAM = 100,000 GRAM
```

ATH 从 `100,000 GRAM` 的参考市值起步。

## 固定总量

ATH 由 `ATHMaster` 合约发行。初始化时，`ATHMaster` 将总量固定为 `100,000,000 ATH`。

创世之后没有增发函数。`ATHMaster` 不实现管理员铸造、暂停、黑名单、转账税、强制转账或紧急提取。

首次发行只做一次，通过 `DeployTreasurySupply` 完成：它把全部供应量发往国库 ATH 钱包。创世发行无法重复执行。

总量只会因销毁而减少。只有在收到来自持有者地址的确定性 ATH 钱包发出的、经过认证的销毁通知后，`ATHMaster` 才接受销毁。校验通过后，`ATHMaster` 减少 `total_supply` 并发出 `ATHBurnFinalized`。

销毁 ATH 是总量的真实减少，而不是转入一个不再使用的地址。

## 供应分配

ATH 的供应量分为四类：

| 类别 | 占比 | 数量 |
| --- | ---: | ---: |
| 活跃度空投 | 15% | 15,000,000 ATH |
| 初始流动性 | 15% | 15,000,000 ATH |
| 长期协议归属 | 10% | 10,000,000 ATH |
| 市场稳定储备 | 60% | 60,000,000 ATH |

这一分配确定了 Platho 的经济结构：

- 15% 在资金池上线之前，通过应用内活跃度分发给用户。
- 15% 用作初始流动性。
- 10% 锁定在不可变更的长期归属中。
- 60% 注入 MarketStabilitySeller 并在创世时锁定，待资金池上线后的定价冻结完成，再按高于上线价的档位分批售出。

在最终创世时，活跃度空投与长期归属储备由 AirdropPool 和 ATHVesting 的官方 ATH 钱包背书，发布校验器会在正式发布前核对这些余额。`60,000,000 ATH` 的市场稳定储备注入 MarketStabilitySeller 并在最终创世时锁定，由其官方售卖方 ATH 钱包背书，发布校验器同样会在正式发布前核对该背书。储备从一开始就已足额，但在资金池上线之前不会售出；上线时一次性的、以证据绑定的定价冻结将确定档位基准价。

## 长期协议归属

长期归属储备为：

```text
10,000,000 ATH
```

它存放在 `ATHVesting` 中，而非可变更的国库分区。归属节奏写死在合约里：

```text
100,000 ATH per 365-day period
100 periods
10,000,000 ATH total
```

ATH 归属之后，任何人都可以发起领取，但受益人不可更改。合约没有加速、更换受益人、暂停、管理员提取、紧急撤离或酌情释放等功能。

在最终创世时，官方 `ATHWallet(owner = ATHVesting, master = ATHMaster)` 必须恰好持有 `10,000,000 ATH`。校验器还要求上线前已领取额为零、处于空闲阶段、且没有待处理的转账。

这份储备刻意放慢。它为协议的长期发展留出时间跨度，同时不会在上线时把一份 1000 万 ATH 的流动筹码压在市场头上。

## 活跃度空投

活跃度空投总额：

```text
15,000,000 ATH
```

每次成功发布的奖励：

```text
10 ATH
```

每个被接受的胶囊为发送者带来 `10 ATH`，各条通道一视同仁。失败的发布尝试什么也不会带来。

派发按批次进行，而不是逐个胶囊结算。每次派发都带有约 `0.0166 GRAM` 的固定不可回收成本，且该成本与这次派发承载多少 ATH 无关。若每个胶囊之后都结算一次，烧掉的费用会超过这些胶囊所收取的协议费，因此奖励先累积，再一次性到账。

空投由 `AirdropPool` 的官方 ATH 钱包背书，这 `15,000,000 ATH` 正存放在那里。用尽之后，活跃度奖励随之停止。

## 活跃度价格

消息的起步价：

```text
0.0191 GRAM
```

当前确切数值：

```text
私信：      0.0191 GRAM
首次联系：  0.0178 GRAM
公开帖子：  0.0203 GRAM
```

每次成功发布，用户获得：

```text
10 ATH
```

按上线参考价计算：

```text
10 ATH * 0.001 GRAM = 0.01 GRAM
```

这把早期的 ATH 分发与应用的真实使用绑定起来。该奖励是活跃度奖金，而不是退款、返现、折扣，也不是「ATH 会抵消发布所花 GRAM」的承诺。`10 ATH` 的上线参考价值可能低于一个胶囊的 GRAM 成本，这是有意为之：用户以真实使用换取网络的早期所有权，而不是获得保证的补偿。

胶囊定价：公开帖子自 `0.0203 GRAM` 起，私密胶囊自 `0.0191 GRAM` 起。更大的公开或私密胶囊块更贵，因为所选的 1、2、4、8、16 或 32 KiB 正文会改变分片中的执行与存储储备。无论胶囊大小，每个成功定案的胶囊奖励恒为 `10 ATH`。

私密发布默认采用混合安全配置：X25519 + ML-KEM-768 + AES-GCM。私信没有更便宜的经典模式。

官方资金池出现后，ATH 的成交价可能高于也可能低于上线参考价。活跃度奖励不是投资回报，不是盈利预期，也不是价格保证。

## 协议费与用户价格

协议费与用户支付的全部成本是两回事。

协议费：

| 发布类型 | 协议费 |
| --- | ---: |
| 公开帖子 | 0.010 GRAM |
| 混合加密私信 | 0.010 GRAM |

用户价格包含协议费、燃料费，以及在分片中存放该记录的存储捐赠：

| 发布 | 附加金额 |
| --- | ---: |
| 私信 | 0.0191 GRAM |
| 首次联系 | 0.0178 GRAM |
| 公开帖子或评论 | 0.0203 GRAM |
| 头像更新 | 0.0395 GRAM |
| 账户激活 | 0.0600 GRAM |

客户端始终附上两个数额中较大的那个——即创建分片所需的那个。多余部分不会消失：分片只留下自己需要的，其余原路退回发送方。若网络估算高于预期，客户端会在其上再加一份余量；那是余量而非付款，同样会退回。

## 资金池上线

ATH/GRAM 资金池在 `15,000,000 ATH` 的活跃度空投全部分发完毕后上线。

上线顺序：

1. 用户通过真实使用 Platho 获得 ATH。
2. 活跃度空投全部分发完毕。
3. ATH/GRAM 资金池上线。
4. 池后路由证据与定价证据被冻结。
5. 回购分账被启用。

资金池自参考价开始：

```text
1 ATH = 0.001 GRAM
```

初始流动性分配：

```text
15,000,000 ATH
```

按上线价计算的 GRAM 一侧：

```text
15,000,000 ATH * 0.001 GRAM = 15,000 GRAM
```

资金池上线前收取的协议费，为初始流动性的 GRAM 一侧提供全额资金。这属于上线引导的一部分，并不把活跃度奖励变成以 GRAM 计价的债权。

资金池是围绕一个已经通过应用使用完成分发的代币而建立的。这正是 ATH 与「无用户基础的空壳上市」的区别所在。

## FeeAccumulator

GRAM 协议费汇集在 `FeeAccumulator`。

在启用回购分账之前，累积的 GRAM 全部划入国库分区：

```text
accumulated_ton -> treasury_due_ton
```

在分账启用之前，`buyback_due_ton` 不会增长。

执行 `EnableBuybackSplit` 之后，累积的 GRAM 被分开：

```text
50% -> treasury_due_ton
50% -> buyback_due_ton
```

若纳吨金额为奇数，余数留在回购一侧：

```text
treasury_amount = floor(amount * 50%)
buyback_amount = amount - treasury_amount
```

`EnableBuybackSplit` 是不可逆的一次性动作，由不可更改的国库接收方在资金池上线且回购路由冻结之后执行。它是一项真实存在的一次性权力：它无法窃取资金、暂停、紧急撤离或更改地址，但会永久性地把 FeeAccumulator 的经济模型从「仅国库的引导式累积」改为「国库/回购各半」。只有通过发布前检查后才会启用。

Platho 的发布权限刻意做得狭窄，且多为一次性。它们确实存在，就应当被如实说明：国库持有者只部署一次 ATH 初始供应；创世控制者执行封印前绑定与封印；BuybackBurn 的上线控制者只冻结一次池后路由；MarketStabilitySeller 的定价冻结由其上线控制者执行一次；FeeAccumulator 的国库接收方在发布前检查通过后启用不可逆的回购分账。以上任何一项都不是紧急撤离、暂停、升级、管理员提取，也不是对余额的任意控制。

## 回购与销毁

回购通过 `FeeAccumulator` 与 `BuybackBurn` 执行。

BuybackBurn 只接受完整的可执行信封：

```text
51.05 GRAM
```

信封结构：

```text
50.00 GRAM  - STON.fi 报价金额
1.00 GRAM   - 路由转发燃料
0.05 GRAM   - pTON 转账燃料
```

裸的 `50 GRAM` 不是有效的回购份额。回购只以完整的路由信封形式被接受。

路由冻结之后，BuybackBurn 按如下方式执行回购：

1. 只接受来自绑定 FeeAccumulator 的 `51.05 GRAM`。
2. 将该金额记入 `reserve_due_ton`。
3. 收到 `ExecuteBuybackChunk` 时消耗一个信封。
4. 使用冻结的报价与冻结的 minOut。
5. 在内部设定 STON.fi 的截止时间。
6. 通过冻结的 pTON 钱包发送路由。
7. 只通过 BuybackBurn 的官方 ATH 钱包接收 ATH。
8. 校验来源钱包与冻结的 STON.fi 池是否一致。
9. 通过官方 ATH 钱包把收到的 ATH 送去销毁。
10. 只有在收到 `ATHMaster` 的 `ATHBurnFinalized` 之后，才算完成一个循环。

回购是否成功，不由路由器消息、发出的销毁请求或 ATHWallet 的销毁通知来判定。只有当 BuybackBurn 收到来自 ATHMaster 的、经过认证的 `ATHBurnFinalized` 时才算成功。在该定案到达之前，BuybackBurn 仍应被视为待销毁或待重试状态；仪表盘与索引器不得仅因为发出过销毁尝试就把 ATH 记作已销毁。

若销毁未能定案，收到的 ATH 转入重试应付项。`RetryAthBurnDue` 会销毁全部重试应付金额。

## 用户名费用

注册 `.ath` 用户名以 ATH 支付，经由 UsernameRegistry 的官方 ATH 钱包。

价格：

| 名称长度 | 价格 |
| ---: | ---: |
| 4 个字符 | 10,000 ATH |
| 5 个字符 | 1,000 ATH |
| 6 个及以上 | 100 ATH |

UsernameRegistry 只接受恰好等于价格的金额。少付与多付都不会创建名称。

被接受的铸造会经过待定状态，并部署一个 `UsernameNFTItem`。在该 item 得到确认之前，付款不计为收入。item 确认后，金额被拆分：

```text
50% -> treasury_due_ath
50% -> burn_due_ath
```

用户名铸造以用户自己钱包中的 ATH 支付。因名称无效、价格不符或名称重复而被拒绝时，款项通过 ATHWallet 的通知退款路径返还给持有者。UsernameRegistry 不为名称维护单独的外部退款分区。

来自用户名铸造的 ATH，只有在对应 item 的部署得到确认之后，才成为协议收入。

用户名的权威被刻意拆分：`UsernameRegistry` 把名称锚定到唯一确切的 `UsernameNFTItem`，而 item 的状态承载当前所有者。转移 item 即转移名称。item 提供标准 NFT 数据与链上 TEP-64 元数据，其中包含 `name = <username>.ath`；它的元数据不依赖任何 Platho 服务器。名称字节按字面处理，不做显示层归一化：只要每个字节都属于允许集合 `a-z`、`0-9`、`_`、`-`，且长度在 4..16 之间，带前导、尾随、连续或全部为分隔符的名称都是有效的。若 item 部署已经发起、但其 ACK 始终未抵达注册表，`PrunePendingUsernameMint` 刻意保持非破坏性：它不猜测失败，不删除待定状态，也不创建退款应付项。恢复路径是迟到的 `UsernameItemDeployedAck` 或 `UsernameNFTItem.ResendDeployedAck`，因此一个已初始化的 item 仍可成为权威。若 item 部署确实回弹，注册表会请求官方 ATH 钱包退回待定通知。名称与 item 之间的锚点就是地址推导本身：`UsernameRegistry.get_username_item_address(name_hash)` 给出该名称唯一可能所在的地址。部署在其他任何地址上的 `UsernameNFTItem` 都不具权威：客户端、索引器与界面不得仅凭该 item 就认定 `.ath` 名称的归属，也不得在发生转移之后仍以注册表记录中的所有者为当前所有者。

## 头像费用

更新头像的费用：

```text
100 ATH
```

头像更新以用户自己钱包中的 ATH 支付：由其 ATH 钱包向 ProfileRegistry 的官方 ATH 钱包发起一次带通知的转账。

ProfileRegistry 只在全部条件成立时接受更新：

- 金额恰为 `100 ATH`；
- 发送方是 ProfileRegistry 的官方 ATH 钱包；
- 付款钱包是持有者本人的 ATH 钱包；
- 持有者钱包位于基础链；
- 头像哈希不为零；
- 流标识不为零；
- 分片数量在 1 到 16 之间；
- 媒体格式为 WebP。

被接受的更新会生成新的头像版本，并拆分费用：

```text
50 ATH -> treasury_due_ath
50 ATH -> burn_due_ath
```

被拒绝的头像通知通过 ATHWallet 的通知退款路径返还。ProfileRegistry 不为格式错误的头像更新设立单独的退款分区。

ProfileRegistry 负责定价与结算，但不保存任何档案状态：指向头像的认证指针位于持有者本人的 KeyShard 中。图像字节存放在 PublicShard 的 AVATAR 域；客户端从中或从本地缓存拼装出 WebP，并按存储的 `avatar_hash` 校验字节。缺失或被截断的历史会显示为不可用。

## 市场稳定售卖方

MarketStabilitySeller 是一个公开的合约储备，在官方资金池上线之后分发 ATH：

```text
60,000,000 ATH
```

它的目的是减小因流动性稀薄而造成的早期市场扭曲。上线时，一个小池子可能被一小群早期买家大幅推动。一旦如此，那些真正需要 ATH 来在 Platho 中做事的用户，就可能被迫在人为的价格尖峰上买入。

MarketStabilitySeller 在上线价之上建立一道透明的供应阶梯。它按固定规模的档位售卖 ATH。每个下一档都比前一档更贵，且每档都有硬性规模上限。在一次性的、以证据绑定的定价冻结之后，档位表是确定性的，团队无法手工更改。

若早期投机者试图吸走大量 ATH，他们只能按逐档上升的价格从公开储备买入，而不是把稀薄池子里的廉价流动性抽干再转卖给用户。若普通用户需要 ATH 用于 Platho，他们可以按已知的公开档位价买入，而不必用一波需求把小池子拉成垂直线。

该储备不会向市场倾销代币。它不会自行售卖，也不会在没有需求时制造抛压。只有当买家自愿从当前档位买入时才会发生售卖。没有需求时，储备保持静止。

ATH 的链上用途是具体的：

- 注册 `.ath` 名称以 ATH 支付，经由 UsernameRegistry；
- 头像指针更新以 ATH 支付，经由 ProfileRegistry；
- 用户自己钱包中的 ATH，在活跃度分发闸门开启后可降低发布的协议费；
- 已被接受的名称费与头像费产生国库应付项与销毁应付项；
- BuybackBurn 用 GRAM 协议费买入 ATH，并通过 ATHMaster 销毁所购 ATH。

发布以 GRAM 直接从钱包支付。

这让 ATH 的需求与具体的协议动作绑定：`.ath` 名称、头像更新，以及回购与销毁带来的压力。MarketStabilitySeller 只在买家取用下一档时才扩大可得供应，因此早期获取是公开且确定的，而不是被一个稀薄池子主导。

储备只在池后定价冻结完成之后才售卖。

定价冻结是一项真实的一次性上线权力。它依据资金池上线证据，一次性设定档位基准价，随后上线控制者的哈希被清除。此后 MarketStabilitySeller 无法窃取资金、暂停售卖、紧急撤出余额、越过买家或更改价格表。

MarketStabilitySeller 在最终创世时以完整的 `60,000,000 ATH` 储备完成资本化，资金经由认证的储备注资流进入官方售卖方 ATH 钱包，硬性上限为 `60,000,000 ATH`。`mainnet:genesis:verify` 会在正式发布前核对售卖方持有完整储备，且其官方售卖方 ATH 钱包的背书不少于 `60,000,000 ATH`。向官方售卖方 ATH 钱包发起的未经请求的普通 ATH 转账，不会增加计入的储备，不会扩大可售供应，并且可能就此卡住；钱包余额高于 `60,000,000 ATH` 被视为一条警告，而非额外储备。

售卖是池后的独立步骤。资金池上线之前储备不售；上线时一次性的、以证据绑定的定价冻结确定档位基准价，此后档位表即为确定性的，团队无法手工更改。

储备被分为 20 档：

```text
20 * 3,000,000 ATH = 60,000,000 ATH
```

每档带有一个倍数：

```text
x2, x3, x4, ..., x21
```

这形成一道平滑的价格阶梯。随着项目变得更受欢迎，市场获得额外的 ATH 供应，但每个下一档都比前一档更贵。早期需求不会瞬间冲击稀薄的池子，而价格上涨也不会变成一堵让实用型代币难以使用的垂直高墙。

购买公式：

```text
price = ceil(base_tranche_price * current_multiplier * amount / 3,000,000 ATH)
```

`base_tranche_price` 在资金池上线后冻结，与 x1 定价证据完全一致。

按上线价 `1 ATH = 0.001 GRAM`，单档的 x1 价格为：

```text
3,000,000 ATH * 0.001 GRAM = 3,000 GRAM
```

因此：

| 档位 | 倍数 | 每 3M ATH 价格 | 每 1 ATH 价格 |
| ---: | ---: | ---: | ---: |
| 1 | x2 | 6,000 GRAM | 0.002 GRAM |
| 2 | x3 | 9,000 GRAM | 0.003 GRAM |
| 3 | x4 | 12,000 GRAM | 0.004 GRAM |
| ... | ... | ... | ... |
| 15 | x16 | 48,000 GRAM | 0.016 GRAM |
| ... | ... | ... | ... |
| 20 | x21 | 63,000 GRAM | 0.021 GRAM |

单笔购买不能跨越档位边界。这防止了以前一档的价格买到下一档的 ATH。

只有在 ATH 已交付买家之后，GRAM 收入才被确认。若 ATH 转账失败或回弹，储备将被恢复，买家取回其支付的 GRAM 本金，国库应付项不增加。

最后一档 x21 售罄之后，MarketStabilitySeller 不再调节 ATH 价格。自此价格完全由市场决定：流动性、可得供应、对 `.ath` 名称的需求、头像更新，以及回购与销毁的压力。

即便到了 x21 一档，相对于其效用模型，参考估值依然温和：

```text
1 ATH = 0.021 GRAM
100,000,000 ATH = 2,100,000 GRAM
```

到 x21 时，MarketStabilitySeller 已完成其既定的储备释放。此后 ATH 的价格完全由市场通过流动性、使用需求、可得供应以及回购销毁压力决定。唯一剩下的协议性分发，是每年上限 `100,000 ATH` 的缓慢长期归属。

## 国库与销毁分区

UsernameRegistry 与 ProfileRegistry 采用同一套 ATH 费用拆分模型：

```text
accepted ATH fee -> 50% treasury_due_ath + 50% burn_due_ath
```

国库应付项的清算，通过官方 ATH 钱包把 ATH 发往国库接收方。

销毁应付项的清算，通过官方 ATH 钱包发出 ATH 销毁请求。只有在 ATHMaster 中完成销毁定案后，总量才会减少。

失败与回弹路径会恢复各应付分区。记账一直保留到下游的转账或销毁完成为止。

## ATHWallet 记账

ATH 余额存放在确定性的 ATHWallet 合约中。

ATHWallet 处理：

- 创世供应入账；
- 普通转账；
- 带通知的转账；
- 用户名铸造通知；
- 头像通知；
- 销毁请求；
- 通知确认；
- 过期通知的清理；
- 回弹或失败后的恢复。

接受 ATH 作为付款的合约，不接受来自任意地址的直接消息。它们只接受来自自身官方 ATHWallet 的通知。来源钱包的认证在 ATHWallet 内部通过确定性钱包推导完成。

ATH 为通用 jetton 工具提供类 TEP-74 的转账入口，但 Platho 的协议动作使用经过认证的 ATH 通知消息。外部集成不得假定 Platho 的通知流会发出通用的 `JettonTransferNotification`。

ATHWallet 的对外内部转账，由来源侧的待处理记账与来源侧确认共同保护。没有待处理证明时，余额不会仅凭回弹消息体被恢复。

## ATH 生命周期

1. `ATHMaster` 创建 `100,000,000 ATH` 的固定供应。
2. 一次性的国库部署把供应收入国库 ATH 钱包。
3. 供应在活跃度、流动性、长期归属与市场稳定之间分配。
4. 用户从自己的钱包直接付费发布消息。
5. 成功发布记入 `10 ATH` 的活跃度奖励。
6. ATH/GRAM 资金池以参考价 `1 ATH = 0.001 GRAM` 上线。
7. 池后路由证据与定价证据被冻结。
8. MarketStabilitySeller 通过 x2..x21 档位售出储备。
9. 分账启用后，FeeAccumulator 在国库与回购之间划分 GRAM 协议费。
10. BuybackBurn 用 GRAM 协议费买入 ATH，并通过 ATHMaster 销毁。
11. 名称费与档案费产生 ATH 国库应付项与 ATH 销毁应付项。
12. 总量通过认证销毁逐步减少。

## 最终模型

ATH 把 Platho 的三层串在一起：

1. **应用使用**——消息产生活跃度奖励。
2. **付费功能**——名称与头像需要 ATH。
3. **总量收缩**——部分 ATH 费用与回购所得通过 ATHMaster 被销毁。

模型自固定总量与 `100,000 GRAM` 的参考估值起步。面向用户的首次分发与真实的付费使用绑定：消息自 `0.0191 GRAM` 起——当前私信 `0.0191 GRAM`，公开帖子 `0.0203 GRAM`——外加每个定案胶囊 `10 ATH` 的活跃度奖金。更大的公开或私密尺寸档更贵。该奖金不是退款、不是补偿，也不是盈利承诺。当首个 15% 的供应分发完毕后，资金池上线、回购路径开启。

ATH 是 Platho 内部的一枚工作代币：它通过活跃度分发，用于付费动作，降低协议费，沿既定阶梯从储备售出，并通过链上销毁被销毁。走完市场稳定阶梯之后，ATH 未来的价格由市场与协议的使用情况决定。

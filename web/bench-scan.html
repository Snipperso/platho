First-contact scan benchmark

This measures one number: how long this device takes to check a single incoming first-contact record. It is the only work in Platho that grows with how busy the whole network is, so it decides how many users the design can carry. Nothing is sent anywhere — the page generates its own random keys, measures locally, and shows the result.

Takes a few seconds. Keep the screen on and this tab in front.
